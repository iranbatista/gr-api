Só leitura. O token fica só na sua máquina. Cole o JWT do app GymRats abaixo.

como obter o token do app
O token é um JWT que o app guarda após você logar. Formas de obtê-lo:
  • Captura de tráfego (recomendado): abra o app atrás de um proxy (ex.: mitmproxy/HTTP Toolkit), navegue, e copie o valor do header Authorization das chamadas a www.gymrats.app/api.
  • Celular com root / emulador: leia o DataStore do app (/data/data/com.hasz.gymrats.app/files/datastore/).
Posso te ajudar com qualquer uma dessas — é só pedir.
